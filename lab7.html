Lab 7

SQL injection UNION attack, determining the number of columns returned by the query

Descripción

Este laboratorio contiene una vulnerabilidad de SQL Injection en el filtro de categoría de productos. El objetivo es determinar cuántas columnas devuelve la consulta utilizando un ataque UNION SELECT.

Solución

Se intercepta la solicitud con Burp Suite y se modifica el parámetro category. Se prueban diferentes payloads agregando valores NULL hasta que el error desaparezca y la consulta funcione correctamente.

Payloads utilizados

'+UNION+SELECT+NULL-- '+UNION+SELECT+NULL,NULL-- '+UNION+SELECT+NULL,NULL,NULL--
