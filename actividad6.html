Implementación IPSec VPN

Actividad 06

Karina Mendoza Aguado | 179859

Introducción

En esta práctica se configuró una VPN IPsec de sitio a sitio utilizando routers Cisco en el simulador Packet Tracer. El objetivo fue establecer un túnel seguro que permitiera la comunicación cifrada entre dos redes locales a través de una red pública simulada.

Diseño de la Topología

La topología implementada tuvo una estructura triangular conformada por:

  • R1: Sucursal A
  • R3: Sucursal B
  • Router ISP: Simulación del proveedor de servicios
  • Dos switches para conexión LAN
  • Dos equipos finales (PC-A y PC-C)

Esta estructura permitió representar la interconexión entre redes remotas a través de un enlace externo.

Configuración Inicial

Se asignaron direcciones IPv4 a las interfaces GigabitEthernet y se configuraron rutas estáticas por defecto utilizando el comando:

ip route 0.0.0.0 0.0.0.0 [IP_ISP]

Esto permitió simular la salida hacia Internet mediante el router ISP.

Implementación de IPSec

  • ACL: Definición del tráfico interesante entre redes.
  • Fase 1 (ISAKMP): Cifrado AES, hash SHA, clave precompartida y DH grupo 2.
  • Fase 2 (Transform Set): ESP con AES y ESP-SHA-HMAC.
  • Crypto Map: Asociación de ACL, peer remoto y transform set a la interfaz WAN.

Con estos pasos se estableció correctamente el túnel seguro entre ambas sucursales.

Corrección de Error en R1

Error: "Crypto-map is in use by interface"

Solución aplicada:
1. Retirar el crypto map de la interfaz g0/0.
2. Eliminarlo desde configuración global.
3. Corregir la instrucción match address 110.
4. Reaplicarlo a la interfaz.

Verificación

En modo Simulation de Packet Tracer se comprobó que los paquetes ICMP eran encapsulados dentro de ESP (IPsec) al atravesar el router ISP, confirmando que la comunicación viajaba cifrada.

Conclusión

Se logró implementar exitosamente una VPN IPsec de sitio a sitio, garantizando comunicación segura entre dos redes remotas. La verificación confirmó el cifrado correcto del tráfico, cumpliendo el objetivo de la práctica.
