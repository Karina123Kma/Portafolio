SQL INJECTION LAB

Lab 1

Nombre del laboratorio

SQL injection vulnerability in WHERE clause allowing retrieval of hidden data.

Descripción

Este laboratorio contiene una vulnerabilidad de SQL Injection en el filtro de categoría de productos. Cuando un usuario selecciona una categoría, la aplicación ejecuta la siguiente consulta SQL:

SELECT * FROM products WHERE category = 'Gifts' AND released = 1

El objetivo del laboratorio es manipular esta consulta para mostrar productos que aún no han sido publicados.

Payload utilizado

' OR 1=1--

Este payload modifica la condición del WHERE para que siempre sea verdadera, permitiendo mostrar productos ocultos o no publicados.

Proceso

1. Interceptar la solicitud usando Burp Suite.

2. Localizar el parámetro category.

3. Modificar el valor con el payload de SQL Injection.

4. Enviar la solicitud modificada.

5. Verificar que ahora aparecen productos no liberados.

Resultado

La aplicación devuelve productos ocultos porque la condición lógica de la consulta SQL fue manipulada con la inyección.
